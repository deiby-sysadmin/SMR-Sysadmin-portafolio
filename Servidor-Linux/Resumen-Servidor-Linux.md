Servidor Linux — Prácticas Laborales (Servidet Soluciones Avanzadas S.L.)
Este documento resume la configuración técnica del servidor Linux utilizado durante mis prácticas laborales.
Incluye las especificaciones de la máquina virtual, los servicios configurados y la integración con un cliente Windows 10 unido al dominio.
La instalación inicial del sistema no fue documentada, pero se conserva la máquina original y se adjunta una captura de sus especificaciones.


                
                        Especificaciones
| **Sistema Operativo**     | Ubuntu Server 26.04 |
| **CPU Asignada**          | 2 núcleos |
| **RAM Asignada**          | 4096 MB |
| **Almacenamiento**        | 25 GB |
| **Virtualización**        | VirtualBox |
| **Cliente Windows Unido** | Windows 10 |

Servicios Configurados

Samba — Gestión de recursos compartidos y permisos.

SSH — Acceso remoto seguro.

UFW — Firewall básico con reglas personalizadas.

Fail2ban — Protección contra intentos de acceso no autorizados.

Usuarios y permisos — Gestión de cuentas, grupos y privilegios.
