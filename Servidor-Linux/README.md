Servidor Linux — Entorno de Administración y Ciberseguridad.

Este repositorio reúne la configuración, seguridad y documentación técnica de un entorno Linux diseñado para operaciones reales de administración de sistemas. Incluye la implementación del servidor, su integración con un cliente Windows, la gestión de accesos, recursos compartidos, políticas de seguridad, automatización y procedimientos de respuesta ante incidentes.

El entorno incorpora controles de seguridad activos y pasivos, mecanismos de protección frente ataques, procesos de respaldo y restauración, así como demostraciones técnicas que validan el funcionamiento completo del sistema.

Cada subcarpeta contiene documentación estructurada en PDF con capturas, comandos y procedimientos utilizados, organizada para facilitar auditorías, revisiones técnicas y la reproducción del entorno.

Capacidades del entorno:

*Configuración completa del servidor y servicios

*Gestión de usuarios, permisos y políticas de acceso

*Recursos compartidos y control de privilegios

*Endurecimiento de sistemas Linux y Windows

*Protección activa (Fail2ban, firewall, monitoreo)

*Backups automatizados y recuperación ante incidentes

*Validación técnica del entorno mediante demostraciones

*Procedimientos formales y documentación operativa
