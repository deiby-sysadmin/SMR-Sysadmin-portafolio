# Portada – Información del servidor AD01

Este documento presenta el servidor principal de la infraestructura: **AD01**, 
controlador del dominio **contoso.com**.

Aquí se muestra:

- Estado general del servidor
- Roles instalados (AD DS, DNS, DHCP, IIS, WSUS, etc.)
- Información del hardware y red
- Versión del sistema operativo
- Eventos recientes
- Servicios en ejecución

Esta sección funciona como la portada del laboratorio, mostrando la base sobre la que se construyen todos los servicios posteriores.
