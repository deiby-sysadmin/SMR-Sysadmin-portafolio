# Roles instalados en el servidor AD01

En esta sección se documentan los roles y características instaladas en el servidor **AD01**, 
que forman la base de la infraestructura Windows Server del dominio **contoso.com**.

## Roles instalados
- Active Directory Domain Services (AD DS)
- DNS Server
- DHCP Server
- IIS Web Server
- WSUS
- Servicios de archivos y almacenamiento
- Servicios de Escritorio Remoto
- NPAS (Network Policy and Access Services)
